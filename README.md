# お弁当づめ

形のちがうおかずを、お弁当箱にすき間なく詰める1日3箱のパズル。

- 遊ぶ: https://satou-aaaaa.github.io/bento-zume/
- 下のおかずを押して選び、箱のますを押すと詰まります。同じますをもう一度押すと向きと場所が変わります。詰めたおかずを押すと台に戻ります。
- 今日の3箱（小・中・大）はだれでも同じで1日1回。上級（特盛2箱・仕切りあり・ヒントなし）、練習（何度でも）、好きなだけ続けられるとことん、出会ったおかずが並ぶおかず図鑑があります。時間制限はありません。
- 実績（12個）と、遊んだ日のカレンダー。取りこぼした日（7日以内）はカレンダーからあとから遊べます（連続の日には入りません）。
- 箱は先におかずに切り分けてから出すので、必ず詰め切れます。完成すると、その箱の詰め方が全部で何通りあるかが分かります。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（箱の形と答えは入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
```
